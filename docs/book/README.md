**1부 — 예측마케팅이란 무엇인가**

- 2장 마케터를 위한 예측분석 입문 — 군집화(66), 경향성 모델(70), 경향성 vs RFM(74), 협업 필터링(76), 예측분석 프로세스(81)
- 3장 **완전한 고객 프로파일 구축** (89) — 데이터 유형(94), 데이터 정비(99), 링크·중복 제거(103), IT 협력(106) ← **반영 완료**

## 사진으로 확인한 도표·그림 수치

### 도표 3.2 — 고객데이터 수집 3단계
| 단계 | 행위 | 인구통계 |
|---|---|---|
| 1단계 | 구매, 웹 행위, 이메일 행위 | 가구 내 지위, 계정 그룹화, 거주 지역 |
| 2단계 | 콜센터 대화, 반품·불만, 상담 노트 | 성별, 전국 인구조사, 업종·규모 |
| 3단계 | 소셜 상호작용, 리뷰·설문, 충성도 프로그램 참여 | 추가 외부 데이터 |

### 도표 3.3 — 구매의 해부학 (판매 시점 수집 가능 25항목)
판매 시간·날짜, 출하 날짜, 대금 청구 주소, 배송지 주소, 구매자 이름, 구매자 성별(이름 유추), 배송 매출, 구매후 경과 기간, 판매 채널(온/오프라인), 판매 제품, 제품 카테고리, 브랜드, 영업사원, 판매 가격, 적용 할인, 발생 매출, 제품 원가, 판매 마진, 납부 세금, 연관 배송 매출, 최초/반복 주문 여부, 주문 내 제품 수, 제품 유형, 사용 기기 유형.

### 도표 3.5 — 고객 프로파일 예 (구역별 항목) → 기획서 2-6절 표 참조

### 도표 7.2 — 생애주기 세그먼트 (정의/목표)
예상고객(미구매), 신규고객(최초 90일 미만), 반복/활동(2회 이상), 이탈위험/비활성(90일 미구매), 유효기간 경과(1년 미구매). → 기획서 2-1절.

### 그림 8.1 — 가치 기반 전략 (높은/중간/낮은 가치) → 기획서 2-4절
세그먼트 비율: 상위 10% VIP / 다음 60% 평균 / 하위 30% 수익성 낮음. 책 사례 지출: 600 / 120 / 30달러.

### 도표 8.2 — 가치 변화 행렬 (최근 12개월 × 이전 12개월), 7개 세그먼트 번호
### 도표 8.3 — 가치 변화 예 (행=최근, 열=이전, 합계 268,000) → 기획서 2-4절 표
### 도표 8.4 — 순손익 예 (높은 $600×3,000 / 중간 $120×9,000 / 낮은 $15×-14,000 = 합계 +$2,670,000) → 기획서 2-4절 표

### 그림 9.1 — 할인율별 신규 고객 획득 비율 (30% 초과: 2011→2014 = 36%→27%, 업계 평균 31%) → 기획서 2-5절 표
### 도표 9.2 — 신중한 의사결정 vs 신속한 의사결정 (주기 6개월/1~7일, 접촉 10회/2회, 주문 $30,000/$200 등) → 기획서 2-5절
### 도표 9.3 — B2B 리드 점수 4단계 (가산점 / RFM / 예측 리드 점수 / 후속 행위 점수)
### 도표 9.4 — 이메일 세그먼트별 개봉률·클릭률 (마니아·신참·길거리쇼핑객·잠꾸러기·유령) → 기획서 2-5절 표
### 그림 9.5 — 최적 발송 빈도 (매출·발송비용·수신거부 손실 곡선)
### 그림 9.6 — 발송 빈도 감소 의사결정 흐름도 → 기획서 2-5절
### 그림 9.7 — 마진 유지하며 수신거부 1.5%→1.1%
