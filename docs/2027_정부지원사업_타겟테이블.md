# 2027년 정부 예산안 기반 — 프랜스 타겟 정부지원사업 테이블

작성일: 2026-11-10 / 성격: 공개 보도 기반 1차 정리 (공식 사업별 세부내역서 대조 전)

## 0. 먼저 확인할 점 (기준일 정리)

- 2027년도 정부 예산안(총지출 820.9조원)은 **8월 31일~9월 1일 부처별 브리핑으로 발표**되었고 9월 초 국회에 제출됨.
- **10월 30일**에 있었던 일: 국회 예결위 공청회(예산안 심사 본격 착수), 국회예산정책처(NABO) 「2027년도 예산안 분석 시리즈」 발간. 시정연설은 11월 2일.
- 따라서 아래 금액은 "정부안"이며 **국회 심의 중(확정 아님)**. 12월 초 확정 전까지 증감 가능.
- 이번 조사에서는 외부 사이트 본문 열람이 막혀 검색 요약만 사용함. **AI바우처·데이터바우처·클라우드 바우처의 2027 사업별 금액은 확인하지 못함** (아래 "미확인" 표기). NABO 분석 자료(산업통상자원중소벤처기업위원회 / 과학기술정보방송통신위원회 분)에서 사업명 단위로 대조 필요.

## 3. 우선순위 제안

1. **1순위 (공급기업 등록)**: AI바우처, 데이터바우처, 소상공인 디지털/SaaS 도입 계열. 수요기업이 바우처로 프랜스 솔루션을 구매하는 구조라 매출과 직결됨.
2. **2순위 (자금 확보)**: TIPS, 모두의 창업. 예산이 확대돼 경쟁 대비 기회가 큼.
3. **3순위 (모니터링)**: 모두의 AI, 스마트공장. 사업 설계가 공개되면 파트너 참여 여지를 검토.
